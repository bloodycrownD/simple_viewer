# Simple Viewer（WinUI 3）PRD

## 背景

现有 **Simple Image Viewer** 基于 Python + PySide6，已实现本地看图、目录浏览、GIF、旋转/全屏、回收站删除、快捷键移动到预设文件夹、可配置快捷键及命令行启动等能力。希望在 **纯 Windows** 平台使用 **WinUI 3** 重写，在保持日常可完全替代旧版的前提下，提升界面观感与浏览性能（尤其大图与同目录切换体验）。

## 目标（含成功指标）

| 目标 | 成功指标（可验证） |
|------|-------------------|
| 功能替代 | 旧版日常使用的核心能力均可在新应用中完成；用户可停用 Python 版 |
| 浏览流畅 | 同目录连续切换图片时，无明显卡顿或长时间空白；体感延迟目标 **&lt; 100ms**（常规尺寸 JPG/PNG，SSD 本地目录） |
| 大图可用 | 打开 **20MB+ / 4K** 级别图片时，界面不长时间无响应、不长时间白屏；可完成缩放与切换 |
| 界面现代化 | 主界面与交互符合 **Windows 11 Fluent** 视觉风格，观感明显优于旧版 |
| 启动体验 | 冷启动至主窗口可见，目标 **≤ 2 秒**（常规开发机环境） |
| 配置独立 | **不兼容** 旧版 `config.json`；快捷键与移动目标路径通过应用内设置管理 |

## 用户与场景

**目标用户：** 本机 Windows 用户（主要为开发者/重度本地文件使用者）。

**主要场景（混合使用，无单一主次）：**

1. **本地文件夹批量浏览**：打开目录后按自然排序快速上一张/下一张。
2. **看图 + 分类归档**：浏览过程中用快捷键将当前图片移动到预设文件夹。
3. **单张查看**：直接打开单个文件，旋转、全屏查看。
4. **命令行唤起**：由脚本或其他工具传入文件路径、目录及索引参数启动。

## 范围

### 包含范围

- **打开与浏览**
  - 通过 UI 或命令行打开单个图片文件。
  - 通过命令行打开指定目录（`-d` / `--directory`），并按自然排序浏览同目录图片。
  - 支持命令行指定目录内起始索引（`-i` / `--index`）。
  - 上一张 / 下一张（含循环到首尾）。
- **显示**
  - 图片适应窗口显示（保持宽高比）。
  - 左旋 / 右旋（90° 递增）。
  - 全屏切换。
- **格式**
  - 与 Python 版一致：**png、jpg、jpeg、gif**。
- **GIF**
  - 动图正常播放。
- **删除**
  - 将当前图片移至系统**回收站**（非永久删除）。
- **移动到文件夹**
  - 支持通过快捷键将当前图片移动到用户配置的预设目录（行为对齐旧版「分类归档」用法）。
- **快捷键**
  - 应用内**设置页**可视化配置：按键组合、对应命令（上一张/下一张、旋转、全屏、退出、删除、移动到某路径等）。
  - 至少支持配置多条「移动到指定文件夹」类快捷键。
- **命令行**
  - 支持：`viewer <文件路径>`、`viewer -d <目录> [-i <索引>]`、`-h` / `--help` 帮助说明。
- **状态栏**
  - 展示：文件名、文件大小、图片尺寸、当前序号（如 `3/120`）。

### 不包含范围

第一版明确不做以下能力（即使技术上可行，也不纳入本期验收）：

- 图片编辑（裁剪、调色、标注等）
- 云同步 / 在线图床
- 压缩包内看图（zip / rar 等）
- RAW 及超出上述四种类型的专业/扩展格式
- 注册为系统默认看图程序
- 底部缩略图条 / 胶片条
- 多窗口 / 多标签页
- 旧版 `config.json` 的导入或兼容

## 核心需求

1. **看图与目录浏览**：用户可打开文件或目录，在同目录内按自然排序连续浏览图片。
2. **显示控制**：用户可对当前图片进行适应窗口显示、旋转与全屏操作。
3. **GIF 播放**：打开 GIF 时自动播放动画。
4. **安全删除**：用户可将当前图片删除至回收站，并自动切换到下一张可用图片（或无图空状态）。
5. **分类归档**：用户可通过可配置快捷键，将当前图片移动到预设文件夹。
6. **快捷键设置**：用户可在设置页配置快捷键及移动目标路径，无需编辑旧版 JSON。
7. **命令行与状态信息**：支持脚本化启动参数；状态栏持续展示当前图片关键信息。

## 验收标准

### 打开与浏览

- [ ] **Given** 用户通过 UI 选择一张 `png/jpg/jpeg/gif`，**When** 打开成功，**Then** 图片居中适应窗口显示，状态栏显示正确文件名、大小、尺寸。
- [ ] **Given** 目录内有多张支持格式的图片，**When** 用户触发「下一张/上一张」，**Then** 按自然排序切换，序号信息更新（如 `n/m`）。
- [ ] **Given** 已在目录末张，**When** 用户触发「下一张」，**Then** 循环到第一张（与旧版行为一致）。
- [ ] **Given** 命令行执行 `viewer -d <目录> -i 10`，**When** 目录内文件数 ≥ 10，**Then** 打开该目录自然排序后的第 10 个支持格式文件。

### 显示与 GIF

- [ ] **Given** 已打开静态图，**When** 用户左旋/右旋，**Then** 画面按 90° 更新且保持适应窗口。
- [ ] **Given** 已打开静态图，**When** 用户切换全屏，**Then** 进入/退出全屏且图片仍正确显示。
- [ ] **Given** 已打开 GIF，**When** 停留查看，**Then** 动画持续播放直至切换图片或关闭。

### 删除与移动

- [ ] **Given** 当前有打开的图片，**When** 用户执行删除，**Then** 文件进入回收站且不在原目录；界面显示下一张或空状态。
- [ ] **Given** 已在设置页配置「Ctrl+数字 → 移动到路径 P」，**When** 用户按下该快捷键，**Then** 当前文件移动到 P（目录不存在时自动创建），并切换到下一张可用图片。

### 设置与命令行

- [ ] **Given** 用户在设置页修改快捷键，**When** 保存后重启应用，**Then** 新快捷键生效。
- [ ] **Given** 用户执行 `viewer -h`，**When** 查看输出，**Then** 包含文件路径、`-d`、`-i`、`-h` 的说明与示例。
- [ ] **Given** 用户仅有旧版 `config.json`，**When** 首次启动新版本，**Then** 不要求自动迁移；应用使用默认配置或设置页内配置即可正常工作。

### 非功能（体验向）

- [ ] **Given** 同目录 50 张以内常规 JPG/PNG（单张 &lt; 5MB），**When** 连续快速切换 20 次，**Then** 无明显长时间白屏或界面假死。
- [ ] **Given** 单张 20MB+ 或 4K 图片，**When** 打开并切换全屏/适应窗口，**Then** 应用在合理时间内恢复可操作（无持续无响应）。
- [ ] **Given** 冷启动应用，**When** 无命令行参数，**Then** 主窗口在约 2 秒内可见。
- [ ] **Given** 主界面展示，**When** 与旧版对比，**Then** 视觉风格符合 Win11 Fluent，工具栏/状态栏/设置入口清晰可用。
