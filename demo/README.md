# 打标签 + 瀑布流 交互原型

为「图片打标签与瀑布流浏览」PRD 做的纯前端交互原型（HTML + CSS + JS，无依赖、无需构建）。

## 怎么打开

直接双击 `index.html`（或拖进浏览器）。图片来自 picsum.photos 占位图服务，**需要联网**；离线时会显示彩色渐变占位块，不影响交互验证。

右上角「重置数据」可清空本地改动重新开始。

## 覆盖的 PRD 行为

| 模块 | 交互 |
|------|------|
| 瀑布流 | 多列、按图片宽高比排布；打开时模拟"递归扫描渐进呈现"（顶部可见扫描进度） |
| 文件名标签协议 | 打标即"改名"：单图查看页可见完整文件名 `sunset[风景 已修].jpg`（标签段高亮）；瀑布流中文件名展示剥离标签段 |
| 左侧标签栏 | 目录树行式节点（Eagle 风格）：组行（chevron + 徽章 + 右对齐计数）与缩进子标签行（竖向连接线 + 计数）；组可新建/重命名/删除/切换互斥⇄兼容，标签可重命名（提示影响张数）/删除；点击组行展开/折叠；行内管理按钮悬停浮现 |
| 互斥组 | 组内单选：打新标签自动替换同组旧标签（toast 有提示）；chip 带单选圆点样式 |
| 拖拽打标 | 拖拽卡片到左栏标签行 = 打标（互斥组按语义替换）；选中集内的卡 = 整集打标，未选中卡 = 单卡；目标行 dragover 高亮 |
| 标签筛选 | 点击标签一律 = 筛选（多标签 OR 语义，再点取消）；筛选条显示条件、命中数，可单删/清空 |
| 单图查看 | 双击缩略图进入，←/→ 翻页，Esc 返回；右侧详情栏：图片信息（文件名/大小/尺寸/序号）+ 当前图标签 chips（✕ 移除、＋ 打开标签目录添加，已含标签的行禁点） |
| 排序 | 顶部可切换"按文件名（含标签）"与"按发现顺序"——**前者打标后图片位置会跳动**，这是文件名标签模式的固有代价，建议实际体验一下能否接受 |

## 有意为之的简化（与真实应用的差距）

- 不真的读写磁盘文件，"改名"只发生在内存里；刷新后通过 localStorage 恢复标签改动；
- 420 张图全量渲染 DOM，未做虚拟化——真实应用的几十万张需要虚拟化 + 缩略图管线，性能口径见 PRD 验收标准；
- 没有文件被占用、路径超长等失败分支（PRD 中批量操作失败回执在原型中未模拟）；
- 扫描进度、目录树都是模拟数据。

# 复杂筛选器设计稿（filter.html）

为「复杂筛选」需求做的纯前端设计稿（`filter.html` + `filter.css` + `filter.js`，双击即开、离线可用、无外部依赖）。在现有"点击标签 = OR 筛选"之上，补齐 in / not in 与 and / or 任意组合的表达能力。

## 设计要点

| 模块 | 设计 |
|------|------|
| 入口 | 工具栏「⧩ 筛选 ▾」按钮（有条件时带数字徽章 + 高亮）；筛选条「编辑」也可打开 |
| 条件行 | `[包含任一▾/不包含任一▾] [标签多选 chips]`——只做标签的 in / not in；无标签筛选由左栏既有能力覆盖（not in 全部标签在语义上也等价），不在此重复 |
| 嵌套条件组 | 组一律渲染为**卡片**（含最外层根组），卡片嵌套卡片；组头「满足以下 [全部/任一] 条件」= AND/OR；「＋ 条件组」插入子卡片，最深 3 层，可表达任意布尔组合；嵌套层背景色交替 + 左侧 accent 竖线区分层级 |
| 值选择 | 「＋ 标签」弹分组勾选浮层（含各组计数）；已选显示为 chips（✕ 移除）；not in 行整体红色语义 |
| 实时生效 | 无"应用"按钮：命中数（工具栏 + 面板底）、图墙、人话表达式（面板底部 + 筛选条）全部实时 |
| 人话表达式 | 例 `(含(风景/街拍) 或 含(星标)) 且 不含(已修)`；筛选条渲染为 chips + 且/或 + 括号，红 = 否定条件，单 chip 可 ✕ 删除 |
| 快捷路径 | 左栏点击标签 = 往根组追加一条「包含该标签」条件（简单筛选并入复杂筛选，不再是另一套状态） |
| 边界 | 空值条件（未选标签/未输入文本）视为未启用（恒真），构造过程不会瞬间清空图墙；ESC / 点外部关闭面板 |

## 与简单筛选的关系（设计主张）

复杂筛选器是现有点击筛选的**超集**：根组默认 AND，点左栏标签追加 in 条件——用户日常路径不变，需要 not in / 嵌套时打开面板精修。真实实现时 `TagFilterState`（已下沉 Core）可扩展为该条件树结构，求值逻辑与 demo 的 `evalNode` 同构。

## 简化说明

- 140 张模拟图（渐变色块），无缩略图管线；
- 筛选树持久化在 localStorage（刷新恢复），「重置数据」清空；
- 主题切换按钮验证亮/暗两套观感（变量与 index.html 原型一致）。
