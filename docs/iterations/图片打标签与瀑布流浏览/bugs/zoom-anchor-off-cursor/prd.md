# PRD：单图滚轮放大的不动点回到鼠标位置（bug 轮）

- 状态：已修复（2026-09-26）
- 用户原话：「放大逻辑不对之前中心点是鼠标，现在是固定点」
- 关联：`docs/apm/RULE.md`（XAML 硬约束 · WinUI 几何假设条 / 实机 UI 测试 · 量化探针条）

## 现象

单图详情页滚轮放大时，画面不围绕鼠标位置放大，而是围绕一个固定点——把光标放在图上任意位置滚轮，
放大的「吸入点」都不跟随光标（横图尤其明显，纵向偏移可达图片高度级别）。

## 背景与影响面

- 该行为自 **v1.0.5**（2026-09-25「适配盒=可见区」）起引入：那次改动把图片适配基准从「整窗画布」
  改成「未被 chrome 遮挡的可见区」，随之把 ZoomAt 的变换原点 C 从「宿主中心」改成「按适配盒实算」。
- v1.0.6、v1.1.0 均带着该缺陷发布；期间无自动化用例覆盖滚轮缩放（本机鼠标滚轮/移动注入受限，
  RULE 早已记录「放大类交互留用户实机」），因此一直未被发现。

## 目标

滚轮缩放以光标为不动点：缩放前后，光标下的图像内容在屏幕上位置不变（含横图/竖图两种留白方向）。

## 验收标准

| 项 | 判据 |
|----|------|
| 锚点跟随光标 | 横图/竖图各两个光标位，由内容反解的不动点与光标偏差 ≤ 15 物理像素（原偏差 47~300） |
| 适配不回退 | `fit-verify` 4 组夹具盒与像素带一致、宽高比守恒 |
| 无连带回归 | 单图翻页 72 次零加载失败；图库/筛选/缩略图屏幕外 soak 全绿；单测 120/120 |

## 非目标

- 不改缩放倍率、上下限、全分辨率换源阈值等既有口径。
- 不改拖拽平移、双击复位、旋转行为。
