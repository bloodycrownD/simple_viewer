# tag-filter-select-model Feature PRD

## 背景与变更动机

用户要求侧栏标签的选择逻辑与图片卡片一致：默认单选、Ctrl+点击多选。现状标签筛选是 toggle 累积（默认多选），与卡片改造后的 Explorer 心智不一致。

## 范围说明（相对原需求）

- 无修饰点击标签 = **单选重置**（替换为该标签筛选；多选集下点击也替换）。
- **保留既有习惯**：当前唯一选中的标签再点一次 = 取消筛选回全量（用户在移除「清空筛选」按钮时明确依赖"二次点击取消"路径）。
- Ctrl+点击 = 加/减选（多标签 OR，原 toggle 语义收窄到 Ctrl）。
- 与「无标签」筛选互斥、chip ✕、∅ 按钮等既有行为不变。

## 验收标准

- [x] 无修饰点击标签 A → 筛选条仅 1 个 chip（单选）。
- [x] 再点标签 B → chip 替换为 B（仍 1 个，不累积）。
- [x] 再点 B（唯一选中）→ 取消筛选回全量。
- [ ] Ctrl+点击第二标签 → 2 个 chip（OR）；Ctrl 再点 → 减选（注入不可达，代码与卡片 Ctrl 同构，留用户实机）。
- [x] 74 项 Core 单测全绿，build 通过。

## 测试用例

1. 实机（已通过）：点"无背景"→ chip×1；点"大水印"行 → 替换为"负面标签：大水印"仍 chip×1；再点同标签 → 取消回全量（10 张）。
