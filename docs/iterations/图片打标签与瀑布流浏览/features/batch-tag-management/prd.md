# 批量标签管理（两层语义 + 图库右栏 + 工具栏场景化）PRD

## 背景

当前标签体系实际存在两层实体，但产品行为没有区分它们：

- **配置层**：`TagGroup`/`TagDefinition`（settings.json）——左栏标签库显示的就是这层，所以计数为 0 的标签仍会显示；
- **事实层**：图片文件名方括号段里的标签（TagSpaces 协议）——图片真正的标签。未录入配置组的事实标签，左栏自 2026-09-19（ungrouped-tags-ignore 拍板）起完全忽略。

由此产生三个问题：

1. **删除标签连锁误伤**：现状删除左栏标签/组 = 连锁批量改图片文件名移除该标签（删除组级联组内全部）。删定义的意图往往只是"不想再用这个分类"，不应动图片数据。
2. **批量移除标签无入口**：批量添加容易（拖拽到左栏标签），移除只能进详情页逐图点 ✕（2026-09-19 CR 曾拍板"批量移除收窄"，实践中证明不便）。
3. **工具栏场景混淆**：图库/单图两模式可用按钮不同，现状全部常显、以禁用态区分，且「删除」按钮在图库模式实际删的是背后隐藏的当前单图（语义错位）。

本需求以两层模型重构语义，补齐批量移除入口，并按场景精简工具栏。

## 目标（含成功指标）

1. **两层语义清晰**：配置层操作（删除定义）不碰任何文件；事实层操作（未定义区删除、图库右栏 ✕）才是数据变更，均有确认与回执。
2. **批量移除直达**：图库中选中 N 张 → 右栏一键移除某标签；30 张选中集移除 1 标签 ≤ 数秒完成且回执口径与批量打标一致。
3. **工具栏场景化**：每个模式只看到可用按钮，且删除按钮语义与所在模式一致。
4. **数据不丢**：任何"删定义"操作后 0 个文件被改名；未管理标签始终可见可清理（未定义区）。

## 用户与场景

本地图片库的管理者：大量打标后需要清理与重组标签体系。

- 场景 A：「风景」这个分类不要了，但图片本身别动 → 左栏删定义，图片标签掉入未定义区待处置。
- 场景 B：给 30 张图误打了「废片」→ 选中后在图库右栏点「废片」的 ✕ 批量移除。
- 场景 C：索引里发现一堆没录入组的散标签 → 未定义区逐个「收纳」进组，或连锁真删。
- 场景 D：图库浏览时想批量管理标签 → 右栏常驻显示选中集信息与标签。

## 范围

### 包含范围

1. 删除/重命名语义重构（配置组区）。
2. 左栏新增【未定义标签】区。
3. 图库界面新增常驻右栏（选中集标签管理 + 批量移除/添加）。
4. 工具栏左右分组按模式显隐 + 图库「删除」= 删除选中集（新能力）。

### 不包含范围

- 配置组区维持文件树风格（tag-group-tree-ui 拍板不变；chip 流式仅限未定义标签区）。
- 卡片角标维持忽略无组标签的现状口径（未定义标签只在左栏新区与图库右栏可见）。
- 未定义标签不参与筛选、不作为拖拽打标目标、不做重命名（改名需求走配置组连锁改名）——均为后续可议项，本期不做。
- 单图模式右栏（详情页）胶囊样式与行为维持现状，不统一为圆角矩形。
- 快捷键（翻页/删除/全选等）保持全模式可用，不受按钮隐藏影响。
- 批量收纳（一次收纳多个未定义标签）。

## 核心需求（5 条）

### 1. 配置组区：删除只删定义，重命名保持连锁

- 删除标签 / 删除组：仅从 settings.json 移除定义（组删除 = 组 + 组内全部标签定义），**不改任何图片文件名**；原连锁管线整体迁移至未定义区（见需求 2）。
- 被快捷键绑定引用的标签删除时整体拒绝（现状保护口径不变）。
- 确认文案新口径：删除标签 =「仅移除标签定义，N 张图片上的该标签将保留，并出现在未定义标签区」；删除组同口径（组内标签齐入未定义区）。
- 重命名标签：保持现状连锁（配置改名 + 批量更新引用图片的文件名）。
- 删除定义后，若该标签被筛选树引用，摘除树中引用（口径同现有标签编辑联动）。

### 2. 左栏【未定义标签】区

- 位置：左栏配置组列表**最底部**、空集合时整区隐藏。
- 形态：**tag/chip 流式换行**（复用自研 WrapPanel，区别于文件树行风格），每 chip = 标签名 + 计数（全库计数，数据源为现有 `_latestTagCounts` 减去配置组标签，服务层零改动）。
- chip 主点击 = 弹菜单：「删除」（连锁真删：从所有引用图片的文件名移除该标签，走批量改名管线，**确认对话框展示影响张数与不可逆提示**）、「收纳」（选择目标配置组 → 在该组创建同名定义；目标组已存在重名标签则拒绝提示）。
- 不提供重命名（用户拍板：改名场景由配置组连锁改名覆盖）。

### 3. 图库常驻右栏（选中集标签管理）

- 形态：浮层遮盖 + 可收展（与单图右栏同款机制：展开 280 / 折叠 36 窄条，遮盖式布局铁律——不改变画布/瀑布流布局几何）；图库模式显示，单图模式不显示。（2026-09-23 走查修订：图库右栏改为**布局列与画布同级**——像左栏一样占布局槽，收展改变瀑布流可用宽度触发重排；遮盖式铁律仅约束单图画布侧，浮层遮盖会藏住缩略图。）
- 内容自上而下：
  - 标题行「已选 N 张」（选中总数）+ 收起按钮；
  - 标签并集区：当前选中集的**事实标签并集**（含未定义标签——与单图右栏口径一致，成为脏数据批量清理入口），每 chip = 圆角矩形（区别于单图右栏的全圆胶囊）+ 标签名 + **选中集内计数**（如"废片 18"）+ ✕；
  - ✕ = 批量移除：对选中集中含该标签的图片批量移除（复用批量改名 remove 管线，选中集保持、就地同步、回执沿用成功静默/部分失败 InfoBar）；
  - 「＋ 添加标签」：打开标签目录弹窗的**批量变体**（目录复用，判已选态改为选中集口径：全部图片已含 → 禁点；部分含 → 可点，再点为幂等/替换）；点选后对整个选中集打标（互斥组语义 = 替换选中集内同组旧标签，标题沿用「互斥组设置「X」」）；
  - 空选中态：标签区显示空态提示（「选择图片后可批量移除标签」），「＋ 添加标签」可点但提示先选择图片。

### 4. 工具栏左右分组 + 场景显隐

- **左簇**：打开、打开图库（常显）+ 选择、⧩筛选、删除（仅图库模式显示）。
- **右簇**：返回图库、上一张、下一张、左旋、右旋（仅单图模式显示）+ 设置、主题、全屏（常显收尾）。
- 按钮直接隐藏（非禁用）；隐藏不影响对应快捷键路径（快捷键保持全模式可用）。
- 「选择」按钮补可用性约束（无图库/无呈现集时不响应）。

### 5. 图库「删除」= 删除选中集（新能力）

- 图库模式点删除（按钮或快捷键进入此语义时）：删除当前**选中集**——确认对话框（展示张数）→ 回收站 → 同步图库/索引/选中集清空/命中数刷新；空选中时无操作。
- 单图模式：删除按钮隐藏，**Delete 快捷键仍删当前图**（现状管线）。
- 与筛选联动：删除后按当前筛选条件刷新呈现集。

## 约束与依赖

- 打标即改名协议（TagSpaces 文件名标签）不变；批量落盘管线（分批 25 张、就地同步、幂等、超长预检、失败明细）沿用，本需求只增入口与语义分流。
- 遮盖式布局铁律：图库右栏为浮层遮盖，收展只改变遮盖范围，不改变画布/瀑布流几何。
- 配置校验沿用（标签名合法性、组内/跨组重名拒绝、快捷键绑定引用校验）。
- 本 PRD 显式推翻的历史拍板（需文档同步）：2026-09-19「聚合类 UI 完全忽略无组标签」（ungrouped-tags-ignore）、「批量移除标签能力收窄」（cr-fix-spec 回写的父 PRD 需求 5）、「删除标签连锁删除图片标签」（父 PRD 需求）。

## 风险与待确认项

- **大选中集性能**：Ctrl+A 全选数万张时，右栏并集与逐标签计数需挂选中变化钩子增量重算（实现层关注，验收含 30 张常规场景）。
- **未定义区 chip 数量失控**：极端情况下未定义标签可能数百个——chip 区需限高滚动（实现细节）。
- **删除选中集与回收站**：确认对话框口径、部分文件被占用失败时的回执（沿用批量回执，实现层验证）。
- Ctrl+A 全选接管本就仅在图库模式生效（单图模式不触发），『选择』按钮隐藏不影响该口径；快捷键表内命令（Delete/翻页等）保持全模式可用。
