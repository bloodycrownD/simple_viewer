# ungrouped-tags-ignore Feature PRD

## 背景与变更动机

用户发现侧栏出现"未分组"虚拟组兜底展示无组标签，认为不合理：本应用 UI 创建标签必须经组（理论上标签一定有组），无组标签属存量脏数据（外部工具写入/手动改文件名/组配置被删），不应作为一等公民展示。**推翻 2026-09-19 早前 4679a12 的"曾见即留"兜底设计**（及 spec Step 9 原始的虚拟组设计）。

## 范围说明（相对原需求）

- 聚合类 UI **完全忽略无组标签**：侧栏"未分组"虚拟组（含"曾见即留"记忆）、卡片角标（对齐 demo 只遍历组内，"+N"按过滤后计数）、筛选 chips 未分组回退。
- **右栏 chips 保留显示全部标签（含无组）且 ✕ 可移除**——有意偏差 demo（demo 也跳过无组）：它是清理存量脏数据的唯一 UI 出口；移除管线本就按名落盘与组无关。
- 归组途径：配置组内新建同名标签即自然"收编"文件名中的同名标签（按名匹配配置）。
- 互斥语义层不变：组外标签在互斥替换中保留是正确语义（既有 2 项测试覆盖）。
- 目录选择器本就只遍历配置组，零改动。

## 影响模块与接口

| 模块 | 变更 |
|------|------|
| ViewModels/TagSidebarViewModel | 删虚拟组生成/曾见即留/ForgetUngroupedTag/未分组编辑命令/常量与视觉字段 |
| ViewModels/MainViewModel | 删拖拽未分组兜底与重命名/删除的死分支、筛选回退；FindGroupByTagName 兜底保留（chips ✕ 出口） |
| ViewModels/GalleryItemViewModel | Badges/BadgeLine 按组内过滤，"+N"按过滤后计数 |
| Views/TagSidebarControl(.xaml.cs) | 删未分组视觉 x:Bind 分支与灰蓝色特判 |

## 验收标准

- [x] 文件名带无组标签时，侧栏不出现"未分组"组（脏数据不进聚合 UI）。
- [x] 卡片不显示无组标签角标，"+N"不计入。
- [x] 单图右栏 chips 显示无组标签，✕ 移除按名落盘（实机：photo_99[神秘标签].jpg → photo_99.jpg）。
- [x] 配置组内新建同名标签后该标签自然归组（计数/侧栏/角标恢复显示）。
- [x] 71 项 Core 单测全绿（互斥语义测试不受影响），build 通过。

## 测试用例

1. 造 `photo_99[神秘标签].jpg`（无组标签）：侧栏无"未分组"组、目录选择器无此标签（实机通过）。
2. CLI 直开该文件：右栏 chips 显示"神秘标签"，✕ 后磁盘文件名变 photo_99.jpg（实机通过）。
3. 互斥替换组外标签保留（T-TG_09 等 2 项既有测试，零改动通过）。
